🔍 5 Mục Kiểm Tra Cấu Hình Trong Meta Developer:
  1. Đã thêm sản phẩm Facebook Login vào Meta App.
  2. Khai báo đúng App Domains (miền của ứng dụng này).
  3. Khai báo chính xác Valid OAuth Redirect URI (Copy ở trên).
  4. Thêm miền của bạn vào JavaScript SDK Allowed Domains.
  5. Đã cấu hình trường Website URL khớp với URL hiện tại.

⚠️ Trường hợp App đang ở chế độ Phát triển (Development Mode):

Nếu Meta App chưa chuyển sang chế độ Live (Kích hoạt), chỉ các tài khoản Facebook có vai trò là Quản trị viên (Administrator), Nhà phát triển (Developer) hoặc Người kiểm thử (Tester) được thiết lập trong mục "Vai trò" (Roles) của Meta App mới có thể đăng nhập thành công. Các tài khoản Facebook khác sẽ bị hệ thống Meta từ chối truy cập.

Mở luồng đăng nhập nhanh bằng tài khoản Meta để cấp quyền liên kết tự động.

Đồng bộ bằng Page Access Token (Mượt mà, Bỏ qua lỗi App ID)

Nếu bạn không muốn tự tạo App ID phức tạp, cách tốt nhất là sử dụng mã Access Token (sinh ra từ cổng API Explorer) để đồng bộ trực tiếp mượt mà mà không sợ lỗi chặn popup.

💡 Hướng dẫn lấy Page Access Token nhanh nhất? ▼

1. Truy cập trang Meta Graph API Explorer.

2. Tại cột bên phải, chọn Meta App mặc định hoặc App của riêng bạn.

3. Trong ô quyền (Permissions), nhấn thêm pages_show_list, pages_read_engagement, pages_messaging.

4. Chọn Token đại diện là Fanpage của bạn, nhấp **Generate Access Token** và copy chuỗi mã dài dán lên ô trên.

Đồng bộ bằng Facebook Cookie & User Agent SIÊU TỐC

Phương thức bóc tách trực tiếp thông qua API cookie người dùng. Hệ thống sẽ trích xuất mã UID, phiên đăng nhập an toàn mà không cần tạo App ID.

💡 Làm sao để lấy chuỗi Cookie Facebook chính xác?

  1. Truy cập facebook.com và đăng nhập tài khoản của bạn.
  2. Nhấn phím F12 (hoặc chuột phải chọn Inspect) -> chọn tab Console.
  3. Dán dòng lệnh sau và nhấn Enter để copy tự động Cookie: copy(document.cookie).
  4. Dán chuỗi vừa copy được vào ô "Cookie Facebook" ở phía trên.
